# تێلیپرۆمپتەر (Android)

Kotlin + Jetpack Compose + CameraX. دەق دەخشێت، کامێرا نیشان دەدات، ڤیدیۆ تۆمار دەکات (Movies/Teleprompter).

## دروستکردنی APK
1. **Android Studio:** Open → ئەم فۆڵدەرە، پاشان Build > Build APK(s). فایلەکە: `app/build/outputs/apk/debug/app-debug.apk`
2. **GitHub (بێ دابەزاندنی هیچ شتێک):** پڕۆژەکە لە repoـێکی نوێ بارکە (main)، Actions > Build APK > Run workflow، پاشان APK لە Artifacts دابەزێنە.

پێویستی: Android 10 (API 29) یان نوێتر.
